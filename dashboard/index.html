How the value is worked out

Every implied value comes from the snapshot's own figures — TVL, seven-day growth, and how long the protocol has run with no token — never from a hand-kept list of names. The same function scores every row.

implied = TVL × category multiple × growth × maturity

  • Category multiple. For each category, the median market-cap-to-TVL ratio of that category's protocols whose token already trades, computed from this snapshot. Categories with fewer than 3 trading comparables fall back to the global median. Multiples are clamped to 0.02–2.00.
  • Growth. The seven-day TVL change, clamped to −60%…+120%, weighted at 0.5: a protocol growing 40% in a week scores 1.20×.
  • Maturity. 0.60 for a brand-new protocol, rising to 1.00 after two years running with no token. A protocol with no listing date is scored as one year old.
